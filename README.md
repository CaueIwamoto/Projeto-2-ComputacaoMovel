# Objetivo/Funcionalidades
  Será apresentado neste projeto, um básico aplicativo de testes para daltonismo. Ele possuirá cinco janelas:
  - Login: onde o usuário realizará entrará no sistema com seu nome de usuário e senha. Após entrar no sistema, o usuário entrará numa tela de testes para daltonismo, contendo três imagens. Ao fim do teste, o usuário será redirecionado à tela "Informações";
  - Cadastro: onde será realizado a criação do nome de usuário e senha da pessoa;
  - Informações: contém uma breve explicação do objetivo do aplicativo e seus respectivos testes;
  - Lista: um registro dos usuários cadastraods no sistema em forma de lista;
  - Deletar: remove e exclui um usuário do sistema, solicitando o nome e senha.

  Para a criação, utilizei o expo.io, onde posso usar a biblioteca React. E para o banco de dados, usei o armazenamento local (AsyncStorate), pois achei mais prático. Com base em todas as estruturas do aplicativo, me inspirei bastante nos exemplos feitos em sala da matéria de Computação Móvel. E para todo o conteúdo sobre daltonismo, fiz pesquisas na internet sobre o assunto, onde deixarei listado no final deste relatório.

# Motivação
  A motivação para criar este projeto foi através de uma conversa que tive com um colega. A minhas minhas ideias, na verdade, eram criar um aplicativo de receitas, onde a pessoa podia registrar uma receita, criando um nome, uma lista de ingredientes e adicionar uma imagem, adicionar receitas favoritas, uma lista das receitas criadas e remover uma lista registrada.
  Porém, acabei desistindo dessa ideia, pois o aplicativo/código ficou muito complexo e trabalhoso de ser feito, então tive a ideia de criar um app de rotina, onde a pessoa registrava suas metas para os dias seguintes, semanas seguintes e meses seguintes. Mas achei a ideia fraca e desisti idem.
  Por fim, conversei com um colega que precisava realizar o projeto e ele me deu a ideia de um aplicativo para testes de daltonismo, onde a pessoa cria uma conta, loga e realiza os testes, podendo também verificar uma lista completa de usuários cadastrados e excluir um usuário com seu nome e senha.
